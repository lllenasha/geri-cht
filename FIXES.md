# Что исправлено

Проект проверен как стартовый шаблон Gulp + Webpack.

## Исправления

1. Исправлен путь вывода CSS в `config/webpack.prod.js`.
   - Был `../css/style.css`, из-за чего CSS мог оказаться вне `dist`.
   - Стал `css/style.css`, поэтому итоговая структура согласована с Gulp:
     `dist/css/style.css` → затем создаётся `dist/css/style.min.css`.

2. Исправлена мобильная навигация.
   - В `src/scss/header.scss` добавлено состояние `.menu-open`, чтобы меню действительно открывалось.
   - Добавлены фон, `z-index`, прокрутка и переход.
   - На мобильных список меню становится вертикальным.

3. Включены готовые JS-модули `addTouchClass()`, `addLoadedClass()` и `menuInit()` в `src/js/app.js`.
   - Теперь бургер реально управляет меню.
   - После загрузки страницы добавляется класс `loaded`.
   - На touch-устройствах добавляется класс `touch`.

4. Исправлены некорректные/пустые `href` в шапке.
   - Логотип ведёт на `home.html`.
   - Пустые ссылки меню заменены на `#`.
   - `book table` ведёт на `#book-table` и может быть подключён к будущей форме бронирования.

5. Добавлен `meta description` в `_head.htm` и язык страницы в `index.html`.

6. Добавлена команда `npm test`.
   - Она запускает `scripts/check-js.mjs` и проверяет синтаксис всех JS-файлов в `src/js` и `config`.

7. Убран `node_modules` из исходного архива.
   - Зависимости должны устанавливаться через `npm ci`/`npm install`, а не храниться внутри проекта.

## Важно

Это именно стартовый шаблон. Реального ресторанного функционала в нём пока нет: `home.html` содержит шапку и пустой `<main>`, а формы, слайдеры, попапы и другие модули находятся в проекте как заготовки и подключаются по необходимости.

FTP в `ftp.js` содержит демонстрационные значения. Перед `npm run deploy` их нужно заменить на реальные данные сервера.
